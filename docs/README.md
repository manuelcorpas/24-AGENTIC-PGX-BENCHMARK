# docs/

Manuscript-facing artefacts. Nothing here is part of the reproduction path: the
analysis pipeline reads and writes `data/` and `figures/` only.

`code/04-prepare-bib-submission.py` reads and writes this directory. It is a
legacy packaging helper for a different manuscript (a Briefings in
Bioinformatics draft) and its input document is not distributed with this
repository, so the script will not run from a clean checkout and is not part of
reproducing any result reported in the paper.
